# rodal3d-catalog

Public stand catalog for the Frutillar TLS / MLS / ULS plots: GeoJSON indexes and a Vue mockup of the catalog site.

Live site: https://ercastil.github.io/rodal3d-catalog/

```
catalog/   stand polygons (no point clouds)
site/      Vue 3 + Vite catalog
```

```bash
cd site
npm install
npm run dev
```

Processing code (pipeline, research) lives in a separate private repository.
